# 按需运动工艺

适用：连续变形、材质切换、角色/有机运动或复杂背景叠加。普通文案修正不必加载。先保留既有项目的输出、时间和音频契约。

## 选机制，不统一风格

- **变成另一物体**：先设计源、目标轮廓与点对应；同一个对象保持 ID。等点数插值只是几何条件，不代表中间形态好看。查看 25%、50%、75% 及关键事件前后一帧；复杂拓扑变化要另设计拆分/合并，不能靠交叉淡化伪装已实现。
- **切换材质**：共享轮廓与调色板索引；材质只改变描边、填充、局部投影/网点。不要在切换时重建对象或丢掉品牌颜色。线框不是物理玻璃，网点不是准确印刷分色。
- **围绕关节或连接点转动**：先明确 pivot，再计算点/局部组变换；不要围绕画布中心旋转整个人物。挂件可由主体姿态在较早时间的采样表达跟随；延迟不能超出镜头/道具所属时段。
- **自然经过关键姿态**：经过点不必每次归零速度。先选择停顿点与穿越点，再选择插值；不要把多个 ease-in-out 硬串成走走停停。循环需要检查虚拟结束时刻与起点的姿态和邻近速度，不要求所有循环在接缝停住。

## 最小验收镜头

1. 开头、每次结构/材质变化的完整画面、结束画面；不只截最好看的一帧。
2. 事件边界 f−1 / f / f+1，另看连续片段。转场中不得跳 ID、丢颜色、漏目标形态。
3. 有手持/接触时局部放大手、脚、支点与遮挡；不能只检查画面包围盒。
4. 最亮、最暗、纹理最复杂的背景帧检查文字。Alpha 使用局部标签底板，不自动铺不透明全屏；装饰在白底变淡应如实披露。
5. 隐藏/入场元素保留必要布局槽或使用明确坐标，避免邻居因 DOM 布局突然位移。
6. 数据显示、曲线/柱高和说明来自同一帧状态；不从三个独立 easing 值计算。

只检查与当前镜头有关的项。源代码、几何测量与截图都不能替代连续视觉检查。

## 时域与性能

沿用项目的 frame/fps 和章节 clock。嵌套 Sequence 中局部帧与全片绝对帧不能混用；抽组件时不改变它所处时域。无需禁用 Sequence，也不引入 RAF、Reanimated 或 SwiftUI 时钟。

静态几何尽量缓存，只有变化组件订阅帧；不要为优化改坏对象连续性。帧检查与预览可降低尺寸，但最终输出契约不被悄悄修改。保持已锁依赖版本；官方最新示例出现新 API 时先核对本地包实际导出，不顺手升级。
