# 可选：中间帧与停滞定位（不是验收门禁）

漂亮关键帧不能证明连续运动成立。需要查“主体是否停住、过渡是否突兀”时，才对**用户明确指定的合法本地 MP4 和区间**运行；不下载被拦媒体，不默认全量跑、不调用模型、不改视频/运行时/艺术库/批准记录。

```bash
python3 scripts/temporal-review.py --input /absolute/local/demo.mp4 \
  --start 0 --end 12 --output /absolute/existing-parent/new-temporal-review \
  --interval 0.25 --roi 0.1,0.1,0.8,0.8 --expected-hold 4,6
```

- 依赖：已有 `ffmpeg`/`ffprobe`、Python 3 标准库，无安装或联网。采用普通本地路径，设计兼容 Linux/macOS/Windows，不依赖 `/proc` 或专有文件描述符接口；实测环境为 Linux，原生 Mac/Windows 未测。输出目录必须**尚不存在**且父目录已存在；包括空目录在内均拒绝复用。输入/输出任一级 symlink、`..`、覆盖均拒绝，命令参数数组传递、不拼 shell。输入前后核对设备/文件身份、大小、mtime/ctime，输出独占新建；Windows reparse 路径也拒绝。这是普通工作目录防误用，不是敌对并发文件系统沙箱；不要在其他进程同时替换路径/文件时运行。源文件只读；输出只含 `temporal-review.json` 和可读 `.md`，失败可能留部分输出，重试须换新目录。
- 单次最长 **120 秒**，最多 **1200** 个样本；采样间隔 ≥0.1 秒，区间至少容纳两个样本。越界/超限报错，不能悄悄截短；长片由人明确选段。探测和解码各有 90 秒技术超时。默认每 0.25 秒取样，均匀名义时间并非原始精确 PTS，报告 `coverage` 明列 requested/actual decoded samples、名义观测范围和未测尾部；样本短缺不伪装覆盖完整，0/1 个样本是技术未检（exit 2），未采样的尾段不判定；变帧率、短事件或周期运动可能漏检/混叠。
- ROI 是**未自动旋转的编码像素坐标系**下归一化 `x,y,width,height`，默认全画面；报告同时给出落地整数像素区域。带旋转元数据的视频先确认坐标。对照全画面与主内容 ROI，防止动态背景掩盖主体停滞；ROI 之外没有被检查。
- ROI 缩至 160×90 灰度（会拉伸），帧差 = 相邻样本逐像素绝对差的均值 / 255，范围 0–1。默认 ≤0.01 且连续 ≥1 秒提示低变化；≥0.25 提示突变候选。可用 `--low-threshold`、`--min-low-seconds`、`--jump-threshold` 明示调整；这些是**可复现的检索参数，不是审美标准**。JSON `curve` 给出每对样本时间与数值。
- `--expected-hold START,END` 可重复，使用视频绝对秒且须位于请求区间；只标注与低变化区间的重合，**不消除发现、不自动通过**。正常静止阅读、结尾留白、镜头 cut 都可能合理；“死帧 0% / 高冲击”仅在确有该镜头目标时讨论，不全局强推。
- 高帧差不代表好；灰度、低分辨率可能漏掉色彩/小物体变化。无音频、语义、全片解码或身份验证。报告没有源文件 SHA256（只有路径/大小/mtime）；不要将其当成防篡改的最终版本绑定证据。

**读报告之后**：实际观看疑点前后与关键状态之间的连续中间帧，核对命题、信息层级、阅读时间、动作因果与退出；必要时用更细采样/不同 ROI 复查。工具不声称已经人工看过，没有截图或视觉结论。退出码 **0 仅表示诊断计算/写入成功**，即使存在低变化和突变也返回 0；参数、路径、解码或写入技术错误返回 2。不能把发现当视觉 failed，也不能把退出 0 写成用户 accepted。

## 离线回归

`python3 scripts/test-temporal-review.py` 自建 4 秒静态、方块移动、先 hold 后移动、突然 cut、背景动而主体静的 MP4。2026-10-27 实跑 20 次调用通过：数值定位与 ROI 对照、hold 不授予批准、非零起点、参数/超范围/重复输出/路径穿越/源及祖先 symlink/损坏视频拒绝；所有源 SHA256 保持不变。另通过 2 次切换平台标签的真实 ffmpeg 执行、无 `/proc`/专有 fd 接口依赖检查及 3 次 mocked 解码数检查（0/1 拒绝，2 明示覆盖不足）。平台标签测试不是原生 Mac/Windows 测试。测试仅数值与安全断言，不冒充人工视觉审片。
