# 任意用户素材：先观察，再选择动作与实现

这是用户素材动画的通用决策协议，不是按动物名称匹配固定模板的分类器。目标是由 Agent 在当前宿主中**实际查看**用户图像或视频，结合用户意图设计适合该对象的动作，再使用真实可用的执行后端。运行入口与授权/Alpha/实拍合成约束仍见 [LOCAL-ELEMENT-ROUTE](LOCAL-ELEMENT-ROUTE.md)。

## 1. 看得到什么，才写什么

- 先确认真实文件、类型、尺寸、透明度、时长（视频）、本地处理权限和使用范围。只读取用户提供/指定的材料，不扩大扫描目录。
- 有图像查看能力：实际打开图像，观察主体、朝向、姿态、可辨认活动部件、背景与遮挡；不能仅凭文件名声称识别。视频必须查看有时间戳的多帧或可播放片段，静帧不能证明原运动。用宿主实际提供的视频查看工具，或经授权通过本地 FFmpeg 抽取所需时间戳帧并实际查看。`temporal-review.py` 只提供运动数值诊断，不输出接触表，不替代看图；probe 元数据也不是视觉理解。
- 当前宿主不能看图/视频，或文件无法访问时，明确缺失证据；请求必要截图/描述或转可用查看路线。不编造观察，也不暗中上传到视觉或生成模型。
- 在项目独立输出资料中记录 `asset-motion-plan.json`（或同等项目笔记）：实际素材路径与 SHA256、用户动作原文、已查看的帧/时间、观察事实、带不确定性的推断、所选动作、需要的层/枢轴、实现后端和剩余限制。这里的观察由真正查看素材的 Agent 填写，renderer 不会自动生成视觉结论。不要把未发生的授权填成 true。

## 2. 用户意图优先，运动取决于结构和场景

先依据用户明确要求决定动什么、怎么动、放哪里；没有明确动作时，依据可见结构给出最少而合理的设计，并说明推断。对象是通用对象，不限生物：柔性部分可摆动，连接部件可绕枢轴转动，刚体可平移/转动，重复支撑部件可错相摆动，发光或信息层可透明度变化。动作幅度、接触关系、节奏与底片透视应服务镜头。

例如，用户要“蚊子飞”可包含整体飞行和可见翼部的快速运动；“蜘蛛爬”需要身体行进与腿的协调；“蝴蝶飞”可能需要慢一些、幅度更大的翼部收展。但这些只是推理示例，不是限定类别、固定频率或脚本中的动物判断。用户要反常/风格化动作时照其意图设计，不用常识覆盖请求。脚本不会从词语自动决定节奏或生物学参数。

## 3. 按实际素材选择最小可执行路线

| 实际输入与意图 | 路线 | 明确限制 |
|---|---|---|
| 单张透明图，整体运动已满足需求 | `rigid`；需通用周期/非均匀变形时可用单层 `layered-rig` | 整图变形不是独立关节动作 |
| 一层或任意数量已对齐透明层 | 通用 `layered-rig`，显式枢轴、逐层关键帧/周期、总轨迹 | 作者编排的独立二维层，没有骨骼、IK、碰撞、足底锁定或三维背面 |
| 未分层单图但要局部部件运动 | 先实际抠图/分层并检查原位重组，再用通用 rig；允许且具备模型时可选生成式后端 | 不能由单图可靠恢复被遮挡结构；缺层不能偷偷改成整图摆动后称任务已完成 |
| 不透明照片或视频需分离前景 | 明确需要分割/抠像/逐帧蒙版的实际工具与许可，先做短样 | 本地脚本不自动去背景，不把矩形贴图称为透明主体 |
| 已有视频主体本身已在运动 | 保留源运动，按需剪辑/合成；提取透明动画需实际抠像工具 | 此 PNG 层 renderer 不把视频解为可动骨骼，也不支持视频作逐帧前景 |
| 要真实生成、复杂形变、转身或不可见部位 | 只有当前宿主确实提供且已授权的图像/视频模型才调用 | 无模型时明确缺口，提供可执行二维方案供选择，不许保证任意素材自动自然运动 |

需要制作分层时保留源；层必须是实际不同内容/经授权复用，透明画布对齐。对羽翼、肢体等重叠部分分别检查裂缝和遮挡顺序。局部旋转可能露出源图没有的区域，必须披露是否补绘及依据。生成/上传/付费另核权限；本地处理许可不等于云上传许可。

## 4. 通用 rig 可执行合同

复用 LOCAL-ELEMENT 合同的 dimensions、fps、帧数、element 起止、总关键帧、plate 和 outputMode，将 element.motionModel 设为 `layered-rig`，提供 `layers`。没有 asset、flapHz 或 minWingScale。任意层 ID 不承载类别语义，列表顺序为背到前；一层也可用，最多64层。

每层例子（需要放入完整合同，路径/权利需替换为事实）：

```json
{
  "id": "moving-part",
  "path": "assets/part.png",
  "rights": "真实的本任务使用授权说明",
  "pivot": [128, 128],
  "allowLayerClipping": false,
  "keyframes": [
    {"frame": 0, "x": 0, "y": 0, "rotationDeg": 0, "scaleX": 1, "scaleY": 1, "opacity": 1},
    {"frame": 59, "x": 0, "y": 0, "rotationDeg": 0, "scaleX": 1, "scaleY": 1, "opacity": 1}
  ],
  "oscillations": [
    {"channel": "rotationDeg", "amplitude": 12, "hz": 2, "phaseDeg": 0}
  ]
}
```

- 每层必须是真实透明的单帧 PNG，所有层共享同尺寸注册画布。动画 PNG 会明确拒绝，需先按意图显式选择/提取静帧或转已实现的视频路线，不会悄用首帧。pivot 是该画布像素坐标；x/y 是该画布像素位移，与 element 总轨迹的归一化 x/y 不同。
- 每层 keyframes 完整填写所有通道、严格递增，覆盖 element 的 startFrame 到 endFrameExclusive−1，使用相同的输出绝对帧。逐段线性插值。每帧独立求值，不依赖播放顺序。
- 先以 pivot 为中心做 scaleX/scaleY、逆时针 rotationDeg，再 x/y 平移；逐层合成后才应用 element 总轨迹。独立层不继承父关节姿态，需要连接运动时由作者写出协调的关键帧。
- 可对 x、y、rotationDeg、scaleX、scaleY、opacity 各加至多一个正弦周期：`amplitude * sin(2π * hz * (frame−startFrame)/fps + phaseDeg)`。phaseDeg 按度换算，hz 为每秒周期。相位可产生交替或错峰，但不是自动步态求解器。
- scaleX/Y 范围 .05..20，不支持负缩放/穿零翻面；opacity 0..1。周期振幅连同基础关键帧需全程保持这些范围，不能暗中截断。hz 不超过 fps/2 是最低采样限制，不保证快速运动看来自然；高速翅膀在低 fps 下应另外设计视觉近似并实际审片，不伪称捕捉真实振翅频率。
- `allowLayerClipping: false` 检查旋转/缩放后的源 Alpha 包围盒四角是否超注册画布，保守拒绝可能裁切；可给所有源层补同样透明边距。它与总 element 的输出边界 allowClipping 独立。允许裁切必须符合意图。此实现不自动增大注册画布。

python "$SKILL_ROOT/scripts/test-layer-rig.py"
python "$SKILL_ROOT/scripts/local-element.py" /absolute/project/request.json --output=/absolute/project/new-result

## 5. 用户看到的验收

先给能证明所需动作的短样，说明真正动的是哪些部分。至少检查主体身份不漂移、连接处不裂、步足接触（如适用）、节奏、Alpha 边缘、底片透视和层次；用户要求真实跟踪/遮挡时不能拿屏幕坐标替代。最终交付仍使用本地路线证据、真实输出和 pending-human-review，用户实际查看后才记录其评价。能力不足时如实指出哪个要求未完成，不能把草稿当作“任何素材自动自然动画”已实现。
