# 优秀网页动效 → 固定时长视频

只读被选中的案例和相关技术资料，不把整个网页复刻为视频。拆解单位是“对象、触发、状态、空间、节拍、结果”，不是 CSS 类名或工具名称。案例选择见 [MOTION-CASEBOOK](MOTION-CASEBOOK.md)。

## 拆解记录

1. **触发**：scroll、click、hover、drag、声音还是自动时间？来源中哪部分实际核验过？
2. **对象身份**：什么持续存在；位置、比例、材质或层级改变后能否认出它？
3. **状态/因果**：变化由什么驱动，结果如何被证明？纯装饰可保留但不要冒充解释。
4. **空间**：哪层遮挡哪层；camera 与对象谁在动；共享元素从哪里到哪里？
5. **节拍**：准备、主要动作、响应、读图停留、退出各承担什么？
6. **转译**：保留哪种关系，删除哪些网页导航/按钮/无限循环，重新创作哪些资产？

不曾实际播放就写“作者文字/源码说明”，不补写镜头速度或视觉感受。需要复刻具体参考的连续动作时先取得可观看的视频/序列。

## 映射表

| 网页 | 导出时间轴 |
|---|---|
| scroll progress、sticky section | `u(t)` 与明确镜头区间；页面长度不是视频时长 |
| hover/click/drag | 导演事件表 `{frame, input}`，只展示有解释价值的输入 |
| RAF 的墙钟 dt | `t = frame / fps`；解析求值或固定步长模型 |
| 浏览器 transition / FLIP | 源/目标矩形 + 时间插值，字体与图片分开避免拉伸 |
| 无尽 idle / offscreen pause | 有起态、变化、结果和结束的短叙事；循环版另定义接缝 |
| 随机粒子 | seed + 粒子身份 + 事件年龄，不依赖遍历/渲染顺序 |
| canvas 图像序列 | 源帧索引由统一时间决定，每帧清画布，检查缺帧与残留 |
| GUI 材质参数 / OrbitControls | 参数曲线/相机曲线；比较时一次只改一个变量 |
| 多窗口/多个独立播放器 | 单一画布图层、统一时钟、明确各 clip trim/start |
| reduced-motion / 高频交互反馈 | 选定一次明确的运动强度与事件序列；如需低运动版本，显式导出减少位移/摇镜的版本，不让渲染机器媒体查询改变成片 |

[Remotion 帧驱动](https://www.remotion.dev/docs/animating-properties)、[确定性随机](https://www.remotion.dev/docs/random) 是实现参考。GSAP/Motion/Anime.js 的术语有启发，但不要求为每个视频安装全部运行时。

## 可复现实现

为每个对象定义 stable id、起终状态、局部事件帧和 easing。主运动用一条进度驱动相关属性；组件支持直接 seek 到任意帧。字体、图片、视频帧与 WebGL 资源就绪后才截帧；Canvas 每帧隔离 transform/clip/globalAlpha/filter/composite 状态。

保留内容含义：路径长度变化要与包到达时间一致；数字变化要来自同一数据；展开/收回维持共享身份；音视频与几何不要各读不同计时器。相机运动需证明信息，不默认“持续环绕”。

UI 的短时延与视频的读图时长不是同一预算。可吸收入退不对称、明确原点、语义错峰、准备/安定等方法，但不把“所有动作低于300ms”或固定弹性曲线变成全片规则。错峰延迟按组/距离/处理次序定义并受总窗口约束；同时比较则同起点。每个动作先给目的和结果，无意义的持续浮动/光噪默认删除。参考取舍见 [REFERENCE-ADOPTION](REFERENCE-ADOPTION.md)。

## 验证与版权

关键运动看连续帧/低速片段，重复与乱序取帧对比，入出和 hold 检查。网页流畅不证明视频可复现，静态截图漂亮不证明节拍合理，code snippet 不证明已看过原作。

只转译方法；品牌图片、付费模板、字体、音乐、模型、作者代码都独立核权。可先自绘简化资产做技术原型，但“占位”与“真实产品/实拍验收”必须分开。
