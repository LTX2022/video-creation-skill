# 设计资产与检索

先决定内容需要什么，再选择自绘、用户素材、授权检索或可用设计工具。流程/数据常用 SVG/Canvas；真实产品/客户图优先原件；复杂插画/空间草图可按 [OPENDESIGN-WORKFLOW](OPENDESIGN-WORKFLOW.md) 交接，不把某服务当必需。

asset manifest 记录来源/作者/许可依据、用途、实际路径、尺寸和占位状态。来源未知就写未知；“可下载”不等于商业使用或再分发许可。图像生成/外部上传/收费服务按用户授权，工具能力不等于权限。

内置 `assets:pexels` / `assets:pixabay` 可在有授权环境变量 key 时生成候选；候选不等于已下载，不自动写成可商用。画幅根据当前项目，不固定1440×3200；素材原始比例与舞台比例分开。key 不进入源代码/日志/交付包。

复杂图需要可编辑图层时明确要求源文件/独立资产；只有扁平截图就不能承诺分层模板。透明素材、黑白底审图、真实底片合成分别命名与验证。最终回到本地帧确定性 composition，不开启旁路网页录屏交付。
