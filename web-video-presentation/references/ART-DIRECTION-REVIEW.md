# 按需美术评审：具体参考、真实画面、有界修订

用于用户要求美术精修、参考级完成度，或实际画面暴露出设计问题时；普通制作仍走原流程，不为每章自动开启一轮“获奖级”审查。本模块补充审图方法，不新增门禁、必填 schema、评分器或依赖。

## 接到已有设计，而非重开一套

先复用已确认的 `shot-design.md`、当前主题、[STYLE-BENCHMARKS](STYLE-BENCHMARKS.md) 的构图/完成度，以及已选用的 [MOTION-DIRECTION](MOTION-DIRECTION.md) 记录；没有该可选契约也无需补建。内容准确、可读性、用户批准的视觉方向及预算优先于评审者偏好。局部精修不借机切换主题、重写文案或增加音轨。

Awwwards / Webby / FWA 仅可作为寻找优秀案例的线索，不是视频验收标准，也不代表本技能获得背书。已有可用参考时优先复用；需要新参考则在当前授权范围内取得具体作品，记录作品/来源、实际看过的截图或片段、想借鉴的设计点和不适用之处。只知道奖项名、作者描述或未观看链接时，标为未核验，不能声称已完成视觉对标；也不为此默认联网、下载或购买素材。借鉴构图与节奏方法，不复制品牌资产、字体或代码。

## 一轮怎么做

1. **看证据**：从现有 golden frames、motion strips 或 review segment 选受影响的代表镜头；检查实际渲染画面并记录 revision/文件、帧或时间区间。静帧判断排版，连续片段判断运动；覆盖关键动作的进入/中间/退出、镜头切点两侧与手机观看尺寸，不只挑漂亮封面；没有可查看渲染时仅提出待验证建议，报告缺项，不假称已审图。渲染仍需既有授权。
2. **分项判断**：只检查适用项，标注观察和依据，不机械打总分。

   | 维度 | 在视频里实际检查什么 |
   |---|---|
   | 字体 / typography | 字体角色与字重、中文断行、字距、目标观看尺寸可读性；纯图形无文字可不适用 |
   | 留白 / whitespace | 主体与边缘的呼吸、密度与必要标签、安全区；不为“大留白”删信息 |
   | 层级 / hierarchy | 第一眼焦点、次级证据、视线路径，与镜头命题一致 |
   | 色彩 / color | 角色与对比、材质分离、实拍/Alpha 底上的可读性；不强制统一某种配色 |
   | 运动 / motion | 动作目的、起止与 hold、对象连续性、过渡是否抢信息；静止是合法选择 |
   | 微交互 / micro-interaction | 仅保留有信息价值的操作反馈，按 [WEB-TO-VIDEO](WEB-TO-VIDEO.md) 转为确定帧事件；不加真实 hover/滚动依赖 |
   | 多画幅 / responsive | 只验已约定横竖屏及安全区中的重排、裁切和文字；不把网页响应式检查变成无限尺寸导出 |
   | 原创性 / originality | 是否为本内容设计，是否只是通用卡片/装饰换皮；列出与参考的取舍，不以新奇牺牲准确性，也不把主观原创判断当版权保证 |

3. **优先修正**：每轮优先处理最多 3 个高影响问题，先内容表达/可读性，再层级与节奏，最后装饰。每项写清位置、现象、最小改法与复查方式；修改必须属于已授权范围。发现的其他问题保留待办，不能隐瞒客观阻断项。
4. **复看结果**：用相同镜头和适用连续区间看修改后的真实输出，比较是否改善及是否退步；保留未解决项。记录放进已有审图/反馈记录；使用 `motion-direction.json` 时遵守其 schema，不向严格 JSON 塞额外自定义字段。不要复制一套审批表。

## 停止与权限边界

普通任务默认最多 **2 轮**上述评审—修订—复查；用户更低的时间/费用/轮次预算优先。问题已解决或剩余仅主观偏好时可提前结束；没有可验证改善、遇到环境/权限阻断或用尽预算时停止美术迭代，说明保留问题与选择。需要改变已批准方向、扩大交付或增加成本，先取得相应确认；“精修”不授权安装工具、购买、外发或绕过最终渲染批准。

这不是两轮后自动通过：未解决的实际缺陷继续按 [QUALITY-GATE](QUALITY-GATE.md) 标记失败/待审，不降级门禁；必须修复的技术/内容问题走原有授权流程，不借“美术迭代”掩盖。用户明确要求更多轮次时，按其范围与预算约定新的停止条件；不把“不断自检直到完美”当作无限成本或无限修改授权。

结论只说实际观察到的改善、遗留问题与未测项，不能靠自评分数、`finishLevel` 或“专家”角色保证获奖效果、完美品质或用户已验收。用户确认与 final 状态仍走原 [FEEDBACK-EVIDENCE](FEEDBACK-EVIDENCE.md) 和质量门。

## 耗时与复盘

沿用 [FIX-AGENT-INTEGRATION](FIX-AGENT-INTEGRATION.md) 的既有项目日志/摘要，不为本模块安装计量工具、启用新服务或强制开启 fix-agent。实际耗时仅记录有起止证据的范围，并区分命令累计与端到端时间；token 仅在工具真实提供 usage 时记录，缺失写 unknown，不按字数估算。源码测试、文档检查和模拟评审不证明美术效果提升；若要比较效果，应使用同一内容和预算的实际前后渲染及真实反馈。
