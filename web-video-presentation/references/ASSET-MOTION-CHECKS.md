# 动作锚点与底板：两个离线复核案例

在同一个画面上，动作接对位置和底板保留正确是两项独立检查。以下是原创素材的实测数据，不是自动识别能力；区域和阈值只适用于相应测试构图。

| 案例 | 通过 | 拒绝 |
|---|---|---|
| 横向喷口 | 源 SVG 已标明实际喷口；相同宽高比缩放和平移后，盲审仍见光流从喷口开始。调整传播时间后，两处下游都延后 12 帧（24 fps），点亮时刻、末帧不变。 | 取最下方不透明点或复用旧屏幕坐标，虽然变化按时出现，真实喷口都没亮。 |
| 分层拨杆 | 从已对齐的 PNG 层判断真实铰链，拨杆向上开合两次，固定件不动。补回目标深蓝底板后，通过独立抽帧和干净目录重渲。 | 第一版以黑底替换目标底板，虽然拨杆动作正确，仍未通过底板检查。固定件不动也不能证明选对铰链；绕装饰钉的负例仍脱开。平图近似重绘未通过源图保真检查。 |

## 按成片复查

拨杆测试为 640×360、24 fps、120 帧，从 0 开始：F18、F58 为两次峰值，F0、F42、F78、F119 为静止对照。先从同构图、正确底板和固定件的静帧制作同规格不透明对照片；这里的两个检查区在任何选定帧都不被运动遮盖。以正确对照片为保护基准：

```sh
python3 /path/to/web-video-presentation/scripts/review_frames.py \
  --before expected-rest.mp4 --after rendered.mp4 \
  --frames 0,18,42,58,78,119 \
  --protect plate:40,15,560,70:3 --protect base:119,194,61,74:3 \
  --out-dir qa/lever-review
```

本例修正版退出 0；旧黑底版退出 1，并保留报告。查看峰值 PNG 中的连接与活动部件；保护区误差本身不判定连接。实际项目重新选择区域和容差，不复用本例像素坐标。

透明母版与黑底版、修正版的动作相同，不经上面的 RGB 对照。另从实际 MOV 解码 Alpha；例如只抽下列六帧，或按需全解码：

```sh
ffmpeg -v error -xerror -i element-alpha.mov -map 0:v:0 \
  -vf "select='eq(n,0)+eq(n,18)+eq(n,42)+eq(n,58)+eq(n,78)+eq(n,119)',alphaextract,format=gray" \
  -fps_mode passthrough alpha-%02d.png
```

本例透明空白保持为 0，固定底座和铰链的实心采样点为 255；边缘存在中间值，峰值 Alpha 与静止不同，两次峰值一致。若实际文件的 Alpha 解不出、整张实心或全空，都不能只凭编码格式或 MP4 画面宣称通过。此检查不证明第三方剪辑器兼容，也不保证扁平图可恢复未拍到的内容。
