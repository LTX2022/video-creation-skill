# 节拍与停留

有声由实际音频、动作完成和读图时间共同决定区间；无声用 explicit 帧时序。不用固定1.8秒下限或8秒上限剪断关系。

## 先定动作关系，再定曲线

| 关系 | 何时用 | 不能混淆 |
|---|---|---|
| 依次（前项完成后） | 到达后处理、获批后执行 | 固定 stagger 可能让结果提前 |
| 并行（共同起点） | 同一事实的姿态/读数、同条件比较 | 所有节点同时亮不等于因果 |
| 错峰（启动有偏移，可重叠） | 同类对象引导视线扫过队列/空间 | 不凭动画顺序虚构真实处理顺序 |
| hold（有意停留） | 建立对象、比较、读取结果 | 不为凑变化哈希加呼吸/粒子 |

用少量命名节拍，如“建立 / 到达 / 获批 / 输出保持”；在一处从 `narrations.ts` 对应 timing/cue 或 `stepTimings` 得到帧区间。它们是分镜/代码命名约定，不是新增 timing 文件或独立时钟。旁白调整只重算这份映射。

动作可包含不等长的启动、运行、到达、余韵、读懂。匀速传送用 linear；软着陆用 ease-out；只有弹性/反馈确有含义才用 spring。不要每个对象都回弹，也不要为了“自然”抹掉必须突然发生的离散状态切换。

镜头切换跟命题，字幕切换跟句级 cue。英文按词边界，中文按视觉宽度/语意，标点不独立开行，字幕通常不超过两行。保留必要对象名/单位，避免整句重复旁白。

静止 hold 合理；ambient 微动须有目的。loop 定义起终状态和接缝，不截断无限 idle。节奏看实际播放或完整连续区间，不能用黄金帧或稀疏样本判定。
