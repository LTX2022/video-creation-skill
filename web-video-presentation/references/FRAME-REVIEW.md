# 离线同帧对照 / Offline frame review

用于已经实际渲染的成片小修：比如推迟提示卡、校正一帧闪烁、检查不该变的位置。

    python3 /path/to/web-video-presentation/scripts/review_frames.py --before original.mp4 --after revised.mp4 --reference reference.mp4 --frames 179,180,184,188,194,200 --protect amber:77,248,39,34:1.0 --out-dir qa/badge-r2

- 需要本机 Python 3.9+、Pillow 9.1+、支持 -fps_mode 的 FFmpeg 与 FFprobe。不启动浏览器，不上传，不自动安装。
- 帧号从 0 开始，按展示顺序而非编码包顺序。最多 16 个互异帧号。瞬间闪变取临界前、临界及临界后；较慢动画取起点、过渡中段和稳定点。正片的时钟、长度或尺寸改变时，不要用此入口假装自动对齐。
- 保护区参数格式为 名称:x,y,宽,高:阈值，可重复。坐标使用未缩放的编码画布，左上为原点，右/下边界不含。阈值是每个采样帧上 RGB 通道绝对误差的区域平均值（0–255），只和原片比较。压缩会造成少量数值差异；阈值按素材和编码选取，并查看区域细节。大区域可能掩盖小物体，给保护对象画紧一些。
- 查看同一帧号的 PNG，并用 JSON 核对输入哈希、帧号、帧/时间对应和保护区分数。参考片仅供比照，不自动判定视觉相似。退出 0 表示输出成功且所配置的保护区通过（未配置时只是对照图）；1 表示保护区超阈值，仍保留对照与报告；2 表示输入、解码或规格错误，不产生新报告。若被强制中断，输出目录可能不完整，不要使用缺少 review.json 或哈希不匹配的对照图。输出目录必须尚不存在，其父目录应已创建。
- 只核对采样点上的不透明 SDR 视频，不验证未抽到的帧、运动流畅度、Alpha、HDR、音轨或剪辑软件兼容。需要时用对应质量检查或实际播放。

实现边界：首条视频轨，MOV/MP4、MKV/WebM、AVI 或 MPEG-TS；不旋转、方形像素、常见不透明 8-bit SDR。核对整个首条视频轨的展示时间戳，但只为指定帧生成图和保护区数值。每片不超过 180,000 帧，画布不超过 8,294,400 像素且任一边不超过 4,096。VFR 不自动转 CFR；不要为了通过验收覆盖原始素材。
