# 文案与画面共写：一张节拍表，不再先写满屏讲稿

用于代码动态图形的内容规划或改稿；已有批准稿只改受影响行。不是新运行时 schema、评分器或额外审批。先交可看的内容方案，再复用既有分镜、音频和 QA；上游研究只在需要解释方法时读 [采用记录](UPSTREAM-SCRIPT-SOURCES.md)。

## 最小工作单元

每行只负责一个观众命题。按下列顺序写；不要把全部制作说明塞进 `script.md` 或 TTS：

| 字段 | 交什么 | 不交什么 |
|---|---|---|
| 来源/边界 | 材料定位、事实、单位/条件、未知项；示意数据明确标记 | 没来源的收益、客户故事、伪精确读数 |
| 观众命题 | 看完本段应能说出的一个判断 | “酷炫”“高级”或章节标题 |
| 可见对象 → 动作 → 证据 | 谁变了、怎样变、观众在哪看出结果；保留对象身份 | 只写 fade、卡片入场、切几个镜头 |
| 旁白 | 画面不能独立说明的条件、因果或意义；无声写空 | 复述每个标签、朗读导演提示 |
| 上屏内容 | 实际要显示的短标签/必要数据、单位、条件；字幕单列 | 默认自动生成口号、重复副标题 |
| 时间与停留 | 估计秒数/帧区间及结果 hold；音频到位后改用实测 | 把字数估时写成测得的音频时长 |
| 制作备注 | 对象 ID、布局/镜头、素材缺项、实现和复核方法 | 作为内容输出或自动送入 TTS |

事实源 → 观众命题 → 可见变化证据 → 旁白补足 → 最小上屏内容。不是要求每行强配旁白，也不要求整片都用模型因果；流程、数据、品牌节奏、实拍注释各选适合的证据。

## 开头与结尾怎么落地

- **开头先兑现小结果**：先露真实结果或同条件反差，再回到输入解释。没有已证实的结果，可展示要核验的问题；不得写“效率提升十倍”再用装饰读数充证据。数据例可先展示实测差异，机制例可先呈现模型现象并标示意。
- **中间让观众跟得上变化**：对象先可辨认，再发生关键操作，最后留结果供读。旁白句界不必切镜；动作没完成就缩文案/加停留，不能硬挤到模板秒数。稳定相机常比转场更能解释关系。
- **结尾回到有证据的结果和边界**：流程注明仍待人审/未执行；数据保留测试范围；机制注明简化；实拍只说片中能见的操作。CTA 仅在任务需要时写，不能自动诱导下载/站外行动或承诺收益。

## 节奏按证明方式选，不按平台硬卡秒数

- **流程证明**：输入状态→关键操作→结果状态→可读停留。例如导出后让文件/成功反馈可辨，再进入下一动作；手、光标和字幕不遮证据。省略等待可以，不能省到因果不成立。
- **结构证明**：同一内容保持对象身份→重排/分组→对照停留。概念动画说明结构，不自动证明真实点击路径或响应速度。
- 官网短循环依赖周围页面的解释；改成独立 TikTok/Shorts 视频时补足“这是什么、改变了什么”，不照搬缺上下文循环或长品牌开场。长解释允许保留必要前提，不能只加速成短片。
- 有留存数据才据此局部调整：峰值也可能是观众没看懂而重看；先查密集代码、名词和读数，不把峰值自动当成功或加速理由。没有留存数据就不编造优化效果。
- 收尾兑现开头；广告单一CTA只是适用选项，知识/静音素材可以结果或边界结束。无“每两秒切镜”“首秒必反转”通用门槛。

这些是同类官方资料与产品视频抽帧后形成的适配建议，不是平台算法结论；来源和观察边界见 [采用记录](UPSTREAM-SCRIPT-SOURCES.md#跨平台节奏补充)。

## 两个有用的小检查

1. **关声音**：能否指出对象、变化和结果？保留单位、条件、必要字幕；“关声音”不是“禁文字”。若内容本来依赖口播，按无障碍需求保留字幕，不伪称纯图形已解释全部。
2. **只听声音**：旁白是否补了原因/条件，而不是逐项念画面？能否说得顺？无声项目不做这个检查，也不补假 TTS；Alpha 是输出格式，不代表一定无声。

同一限定要跨音画成立：例如“仍在测试/计划下一版”，旁白保留这些状态，画面也停在测试/设计示意，不用上线成功勾选替它宣布完成。

正常默认一次聚焦检查：指出具体行、事实/理解问题、局部改法，修完与分镜同步。不默认全库加载、量化打分、长篇自评、多代理循环或无限重写。实际阻断项仍按既有 QA 处理，不能因迭代预算耗尽称通过。

## 接回现有工程

共写表放入现有 `shot-design.md`（无需另造项目文件）。实际有声文本单独进入 `script.md` / `narrations.ts`；无声 step 的 text 为空，时间按 `timingMode: explicit` / `stepTimings`。`outline.md` 写估时及来源。只把已支持的字段映射进 `shot-manifest.json`：命题到 `claim`、来源到 `source`、对象变化到 `motionIntent`、实际显示文字到 `onScreenText`；其余设计约定留 Markdown，不能宣称机器已校验。

字幕由既有音频/timing 管线生成，不是任意新增第二层标签。改旁白后音频指纹、cue 与动作时间重新对齐；留足阅读 hold，不能靠加快 TTS 解决所有冲突。无实测音频时写“估时，未合成/未录音”。

已批准模板的低成本填充只发 [单任务卡](../templates/script-templates/visual-script-task.md) 中对应模式、当前事实和允许字段；不发历史研究与 60 风格。新设计先正常分镜确认，不把内容草稿当模板批准。锁定模板则仍走 [LOW-COST-BATCH](LOW-COST-BATCH.md)，本页不放宽任何合同。

四个可落地的完整前后稿见 [共写例集](../examples/visual-script/README.md)，只有文本与离线数据核算，不代表视频已经渲染。
