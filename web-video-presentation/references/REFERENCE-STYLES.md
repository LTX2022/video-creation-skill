# 参考衍生的四类独立风格

本版已按用户反馈删除 ink-landscape-film，不默认恢复或换名重加。保留下列四类新增实际 SVG 场景，不是四个配色名，也不是名为“Claude”的统一外观。原56个ID保留，总目录60项。每类的默认内容是原创示例，不是客户案例；参考的设计方法不等于复刻作者原片或取得素材再分发权。

| 可选ID | 视觉和动态主体 | 适合 | 不应直接套用 |
|---|---|---|---|
| spectral-material-film | 同一个折叠字形，实色/纸感/网点保持身份切换 | 品牌质感、材料概念、设计展示 | 真实光学折射、客户实物材质测量 |
| rain-platform-film | 夜间站台、列车、旅人和雨伞、灯光/地面反射 | 情绪叙事、城市氛围、故事开场 | 任意角色自动绑骨骼、真实轨道交通演示 |
| particle-depth-film | 稳定粒子和线束的空间形态、近远关系、缓慢相机 | 科技/艺术开场、抽象概念、舞台图形 | 真实物理粒子求解、任意文字自动粒子化 |
| kinetic-wireframe-film | 原创字形轮廓与空间线框、几何结构和明暗对比 | 动感排版、结构/空间概念、设计片头 | 任意字体自动挤出、可编辑CAD/3D模型导出 |

## 选择与修改

遵循 WORKSPACE-SETUP：先确认客户空白项目目录。脚手架正常选择 `--theme=<上述ID>`，默认章节会实际进入对应组件，不需要另外拼接机制演示。`--skip-install` 只是不装依赖，不能当作已经具备运行环境；缺工具先列清单和安装位置。

- 内容入口：对应 `presets/registry.ts` 的 `content`，包括标题、结论和三段语义说明。少量文字服务画面，不把全文搬进标题。
- 视觉入口：`src/video/reference-styles/` 的独立组件。字体/色彩/对象结构、场景细节与运动是明确的源参数；不是任意改 tokens.css 就能全局换掉所有已创作的材质颜色。
- 横竖屏：组件按真实宽高重排/重取景，不只是把横屏缩小塞进去。字幕开启时，主要内容避让既有字幕带（竖屏约60%–73%高度，横屏约80%–94%），不是误把底部27%当字幕起点；无字幕版本是全幅电影式构图，不保证社交App按钮/底栏不会遮挡，发布前按目标平台重审。仅有预留区的图是布局检查，不是已经烧录字幕的成片。
- 时间：默认三段 narration 对应首态/主要动作/收束。源组件采用实际全章帧；语义进度按已生成的三段章内时间映射，雨、环境等仍用实际 frame/fps。改成其他段数应改时间适配，不能继续假装默认三段契约适用。
- 短标题也须实际检查字形和字体；超长内容不可静默截断。必要时重排或改文案，并记录用户选择。

## Alpha 和实拍适用范围

所有新场景都区分根背景与主体，不用删除全部填充来造透明。但“可以输出透明像素”不等于每种风格适合任意实拍：

- 粒子、字形、材料主体更适合局部前景；检查白底可读性，必要的局部底板与阴影要有设计目的。
- 雨夜是环境式构图，通常优先不透明片段；Alpha 可用于经过设计的分层场景，不应把整幅复杂环境生硬盖在人脸上。
- 实拍跟踪、人物遮挡、镜头匹配仍要真实素材和相应实现；新风格不自动获得这些能力。
- 完整 Alpha 编码/目标剪辑软件/真实底片验收独立于这些 SVG 预览。见 ALPHA-COMPOSITING 与 LIVE-ACTION-OVERLAYS。

## 验证与不保证项

类型/源码检查、静态像素、连续动态检查片、真实浏览器、编码/剪辑宿主和客户验收分开记录。不能用前一项代替后一项。每次更换主体、文字、画幅或时间后，至少复核相关静帧、边界帧和连续段落。

风格组件降低重复实现成本，但不保证弱模型在任意题材上自动达到参考视频的设计水平。当前可检查项目见发行包中的本轮验证说明，不以此页的介绍当作全平台通过证书。
