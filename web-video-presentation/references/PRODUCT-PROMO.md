# 产品宣传片：按需导演层

仅在产品发布、功能展示、品牌宣传且需要镜头编排时读取。不是第61套主题，不改变原60风格；普通讲解、机制解释、Alpha或小修改无需加载。沿用 SKILL 的分镜、代表镜头及最终渲染确认门；上游自主制作默认不适用。

## 接到现有流程，不重建流程
1. 在现有 shot-design.md 写“必须展示功能 → 可见产品状态 → 单镜主动作 → 既有 chapter/step → 配方证据”。事实取自授权产品资料；虚构 UI 明标概念演示，不伪装真实截图。已有说明不重复问。
2. 在逐镜头实现前先看能代表最终版式的风格帧。复用已有关键帧/品牌规范；静帧不能证明运镜或缓动。用代表镜头试片验证动作，再按原确认流程展开。
3. 每镜只选有叙事理由的主动作，预算为建立、动作、落位、读取；依次/并行/错峰/hold 仍按 RHYTHM。不给全片规定开场秒数、冲击次数或统一弹性。
4. 从 [精选镜头定位](PRODUCT-PROMO-RECIPES.md) 只读当前一项；选定卡时记录固定 commit、card、variant/style-key、demo 路径、preview 来源和实际查看结果。未取得动态预览则写“预览未核实”，不得声称同款/复刻完成。
5. 实现仍由 narrations.ts 对应 timing/cue 或 stepTimings 驱动。配方只决定动作语法，不引入第二个总时钟。资产变更、文字变更、字幕和声音继续同步原契约。

## 真实 UI 资产：整页与切片必须对得上
在已有素材清单为所用截图补充：来源页面/用户文件、授权范围、采集日期、页面状态、viewport CSS宽高、devicePixelRatio、图片像素宽高、脱敏方式、SHA-256。
切片记录父截图哈希及像素矩形 x/y/w/h；范围须在父图内。动画定位明确使用 CSS像素、图片像素或归一化坐标，并写换算，不能混用。留必要页面上下文，功能操作前后状态须真实对应。对相机推近后的最终文字尺寸及裁切边缘做像素检查。
不读取密钥、不打开客户私有页面，除非已得到该操作授权；公开可见也不等于可再分发。采集失败时用已授权素材或明确的原创概念 UI，不用编造截图替代事实。

## 声音与节拍：可选分析，不是已接入的音轨能力
原 audioSource=tts/provided/none 指逐step旁白，不用于伪装BGM。audioRequested=false继续全静音。没有独立BGM/SFX实现及交付验证时，仅做方法研究；本次没有新增自动混音、音乐下载、节拍识别器或音轨渲染器。
确获授权且项目已有可用混音路径时：先实测音乐，保留原始秒单位瞬态/节拍候选与0.5x/1x/2x歧义；只将需要的事件映射到既有 timing。无音乐时内容节奏优先，不强行卡拍。不要把检测到的每个鼓点变成相机冲击。
输出回测另记编码音轨偏移与音源峰值滞后，不修改源节拍测量来“对齐结果”。可用 scripts/promo-beat-check.py 对人工或工具已测的成片事件残差作只读诊断，见 [数据约定](PRODUCT-PROMO-BEAT-CHECK.md)。它不听音、不找拍、不证明感知同步。

## 许可与独立审片
沿用既有素材来源记录，新增素材须记录实际作者、确切许可URL/版本、来源、下载/生成日期、原文件与处理文件哈希、裁切/调色/剪辑等改动及发布署名。未知许可不进入公开样片；“免版税”不等于无限授权。外部代码及媒体分别核权；Apache代码许可不覆盖品牌截图、音乐或字体。
制作完成后给未参与制作的审片者：当前简报、实际确认范围、必须功能、最终MP4、分镜、所选卡和准确demo/预览证据、素材来源。不要提供预设结论。逐项报告功能真实性、风格一致、动作语法、文字可读/裁切、连续转场、声音与许可；问题必须带帧号/时间，缺输入写无法验证。复用现有 QUALITY-GATE 和 temporal-review，不再要求第二份重复QA。
只复查受影响项。独立审查不等于用户验收；画面检查不等于完整试听。SOURCE-HANDOFF仍默认仅指定源码快照；未请求不自动交付全源码、不打开Workbench、不导出剪映、不发布。

## 能力边界
本分支集成的是方法和固定来源导航，加一个无依赖数值诊断。没有导入上游124卡/150镜头库、媒体、模板、工作台或剪映导出。样片的离线渲染证据不能升级成Remotion/browser、NLE、Windows/Mac或客户验收。
