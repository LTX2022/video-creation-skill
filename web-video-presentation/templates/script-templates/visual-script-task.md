# 给执行模型的一份短任务（复制下面一块即可）

先由审查方填好事实与边界，只给本次所需材料；未知项不得由模型猜。此卡用于内容/镜头草稿，不授权写源码、调用收费模型、渲染或批准。

```text
任务：为【受众】说明【一个目标】。
已定选择（沿用项目，不新增运行时字段）：
- outputMode：【opaque/alpha/composite/both】。
- 声音选择：【none/TTS/provided】；字幕：【开/关】。
- 内容类型：【流程/数据/机制/实拍overlay或本次已定类型】。
- 底片：【已授权素材ID/缺失/不适用】；Alpha不等于静音，overlay不代表底片已就绪。
输入：
- 事实源：【编号+原文/数据+定位】，性质【实际记录/教学示意】。
- 不可删：【数字、单位、条件、未知项】。
- 已定：【画幅、风格/构图、素材ID、字幕选择、时长预算】。
- 本次允许改：【行/字段】；禁止改：【已定设计/事实/其它行】。

先用事实写观众命题，再写可见对象→动作→证据，最后补旁白和最少文字。
只输出一张表：来源及边界｜观众命题｜对象/动作/可见证据｜旁白｜实际上屏内容｜估时与结果hold｜制作备注。
旁白只解释画面缺少的意义/条件；声音选择为none则留空。
制作备注不进旁白或上屏；字幕单列，必要数据/单位/条件不得删。
开头显示有依据的结果/反差；结尾落在真实结果与边界；未要求则不加CTA。
没有事实/素材就列缺项，不造收益、不造数字、不假装已运行或渲染。
时间只标估计；真实音频出现后才标实测，不能把估时改标签冒充实测。
最后只列需核实/冲突；无冲突写“无新增缺项”，不写自评分或长分析。
```

**已批准模板批量填充时不要用上表代替接口。** 改发以下短任务，并附本项目审查方持有的字段定义、源事实与素材 ID；不发可编辑锁/源码/审批证据。

```text
仅输出 {"schema":1,"lockId":"<给定值>","items":[{"id":"<给定值>","content":{<仅允许字段>}}]}。
按所给字段填内容，保留全部指定事实/单位/条件；无内容的可选字段省略。
不加字段、口号、副标签、制作命令、布局、时序、源码或批准。
超预算、缺素材或事实不能适配时，不生成勉强通过的内容，交回问题与itemId由审查方处理。
```

失败说明不属于成功 JSON，不能送入输入预检；由审查方记录阻断。继续用现有 `check-batch-input.mjs`、内容核对及实际画面 QA，不另设评分达标循环。
