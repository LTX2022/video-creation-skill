# douyin-skill — 实用技能类七段脚本模板

> Profile ID `douyin-skill` 为兼容保留，不代表第三方作者身份或代言。
> 约60秒可作为编排起点，实际时长与语速按内容、试读和画面可读性决定；不将历史样本速度写成标准。
> 下文为独立虚构的「学习清单」界面示范，不是现有软件使用说明，也不是实测效率结论。

## 七段结构与独立示例

| 段 | 目的 | 独立虚构口播 | 可见画面 |
|---|---|---|---|
| 1. 问题入口 | 先明确任务，不许诺秒学会 | 这张清单混着已完成和待处理项目，今天只想查看待处理项。 | 展示同一张6行虚构清单 |
| 2. 当前状态 | 指出信息差，不夸大损失 | 第一、第三行已经完成，其余四行还需要处理。 | 逐个标出两种状态 |
| 3. 方案 | 说清一个操作目标 | 在这个模拟界面里，按状态筛选可以暂时隐藏已完成行。 | 标注“模拟界面”，圈出状态筛选 |
| 4. 操作一 | 动作与输入对应 | 打开状态菜单，选中“待处理”。 | 鼠标停留菜单，保持选项可读 |
| 5. 操作二 | 可见地执行并验证 | 应用筛选后，检查留下的是否正好是原来的四行。 | 原行身份与顺序保留，不换一份数据 |
| 6. 结果 | 同输入对照，不虚构绩效 | 已完成行现在不显示，但没有被删除。清除筛选后应能再次看到。 | 切回完整清单，验证6行仍在 |
| 7. 边界与收束 | 提醒适用范围和下一步 | 这里只演示虚构数据的筛选。换成真实软件时，先核对版本和实际行为，再照自己的任务验证。 | 返回同一清单，保留边界说明 |

## 写作与验证清单

- [ ] 每句对应一个可见动作、对象或结果；读数停留经真实试读调整。
- [ ] 对比保持相同输入，不编造“半小时变几秒”等时间或效果数字。
- [ ] 快捷键、按钮名称和命令仅在实际目标软件核对后使用。
- [ ] 模拟界面明确标示；删除、提交等外部状态修改须经用户授权。
- [ ] 不强迫观众点赞、安装或离开平台；收束与已展示任务一致。
- [ ] 不使用第三方作者身份、成段转写或独有尾句。
- [ ] 字幕与画面长度按项目安全区和可读性检查，不要求所有句子采用固定字数或速度。

## 配套主题

保留 `practical-skill`：浅灰基底、深灰文字、蓝色重点；状态颜色同时配文字标识，不只靠红绿区分。鼠标高亮只用于实际演示动作，不伪造点击成功。
