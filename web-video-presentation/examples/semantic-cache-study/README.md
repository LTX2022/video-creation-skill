# 原创机制验证小样：同一个请求，到期就换路

先看 `semantic-cache-boundary.mp4`；封面 `cover.png`，12格联系表 `keyframes.png`。

**14 秒、1280×720、30 fps、H.264 / yuv420p、静音。** 这是独立原创的语义连续机制验证，不是参考视频复刻，不代表全库风格升级，也不保证审美已经获用户验收。

## 看什么
- 单一空间：请求 → 条件门 → 直接复用 / 重新计算 → 响应，不换标题卡。
- 同一张折角“请求1”卡贯穿。第一次 key=`report:v1`、模型时间 `4秒`、到期 `10秒`，命中复用；动画第5.8–7.0秒沿可见外围虚线回流，再评估同一请求。
- 动画第7秒只把模型输入 `now` 改为 `10秒`，`now < expires` 已不成立，走计算路径；key和期限不变，没有缓存写回。
- **动画时间不等于模型时间。** 画内只显示模型时间；动画时间留在关键帧标签和数据。两条路线的动画节奏相同，不能推断执行耗时、物理速度或缓存提速倍数。
- 请求卡移动→条件检查→分支强调→路径穿越→结果停留。最后约2秒读数保持，没有随机噪点，也不要求所有帧都变化。

## 复跑
使用本机已有 Python、Pillow 12.3.0、FFmpeg。本次使用中文字体 `/usr/share/fonts/opentype/noto/NotoSansCJK-{Regular,Bold}.ttc`；主画面与联系表均用指定的CJK字体。无联网、安装、付费API或用户Mac访问。

```bash
python render.py --out-dir /你的路径/cache-demo-new \
  --font /你的本地字体/NotoSansCJK-Regular.ttc \
  --bold-font /你的本地字体/NotoSansCJK-Bold.ttc
python validate.py --artifact-dir /你的路径/cache-demo-new
```

必须显式提供 `--out-dir`，且是新目录或空目录；非空目录会报错退出，不覆盖已有文件，不写脚本/技能源目录。字体通过参数指定，文件缺失或缺少所需中文字形会报清楚，不自动下载。参数支持自行指定本地字体路径，但没有声称已在所有平台实测。验证器只检查指定产物目录并写入/更新 `decode-validation.json`。本次已在独立空白目录完整复跑，并通过无参数、非空目录、缺失字体、缺中文字形四项拒绝测试（`cli-safety-tests.json`）。`model()` 是逻辑来源；`state(frame)` 把视频帧映射到模型输入；`render(frame)` 可独立乱序渲染，没有逐帧累积状态。透明PNG调用同一个渲染函数。

## 实际视觉审查与修补
1. 英文初稿原尺寸帧发现请求圆点遮时间条、条件门标题，做过避让修补；保存 `before-english/` 图片与源码，仅供对照，不含重复旧视频。
2. 独立复核联系表指出英文调试图的文字细碎、主图太小、空白过多。改为中文必要标签、奶油底、大图形、折角请求卡；删除画内动画时钟、调试备注及重复解释。不是把运动数量当美术质量。
3. 独立复核实际查看 `review-zh.png`（1280宽）和 `review-zh-mobile.png`（640宽），接受作为机制验证小样，不称高级风格验收。
4. 继续打开回流中间帧，发现请求卡遮住“重新计算”（`qa-return.png`）。只把回流改到外围虚线轨迹，并去掉该阶段的卡片尾线，避免遮结果字；不改输入、时序或条件。`qa-return-after.png` 为修补后证据。
5. 最终查看中文联系表、封面、原尺寸回流帧。320宽联系表只供看路径连续性，阅读文字应看完整视频或640宽预览。

## 验证与限制
- `validation.json`：边界测试、乱序重渲染一致性、全部源帧hash及本次实测渲染编码墙钟时间。
- `decode-validation.json`：FFprobe格式、420帧完整解码、随机访问与顺序解码逐字节一致、PNG透明通道检查。
- 边界：4秒命中、10秒失效、9.999秒命中、key不同时失效。
- 随机访问顺序：419 / 0 / 210 / 89 / 299 / 150 / 209 / 300。
- 源帧重复是有意读数hold；有损编码会让静止源帧像素不同，不能用编码帧hash唯一率充当运动质量。
- `foreground-alpha.png` 的alpha范围0–255；**未测试透明视频编码，不声称Alpha视频通过**。示意图内部的奶油色对象保持不透明。
- 全片无音轨，没有做配乐或音画同步测试。本片是简洁图形演示，不是复杂角色动画，也不是性能测试。

精确最终计数与MP4的SHA-256见 `FINAL-VERIFICATION.json`。
