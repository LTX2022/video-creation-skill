# 同一真实小样的诊断对照

工具没有“审美通过”。两次都读取相同14秒最终MP4、每0.1秒、主图ROI (0.04,0.25,0.92,0.6)。解码140个样本，名义覆盖0–13.9秒，最后0.1秒未采样。

默认低变化阈值0.01把两个约7秒区间都列为低变化，尽管请求卡确实在移动。这说明小主体运动被整体灰度均值稀释，默认数字不能代替看图。

经实际查看对象运动后，用0.001及最短0.6秒复查，定位到0–0.7、1.7–2.4、5–5.7、7–7.7、8.7–9.4、12–13.9秒。这些主要对应建立、条件辨认和结果停留。声明hold只注释，不删除发现；不为获得“零静止”给画面加噪点。
