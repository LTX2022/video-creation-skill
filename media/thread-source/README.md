# THREAD / 一线 — 连续对象设计小样

原创虚构产品，14 秒，1280×720，30 fps，420 帧；自绘矢量式形状、自合成提示音。无实拍、无第三方商业素材、无 TTS、无付费 API。不代表真实产品功能/性能。

## 复跑
已用 Python 3、Pillow、NumPy 与系统 FFmpeg 实际生成。字体使用系统 Noto Sans CJK（SIL OFL；字体未打包）。

```sh
python render.py --out-dir /your/empty/thread-render --font /path/to/font.ttc --bold-font /path/to/bold-font.ttc
```

输入是源代码；输出 `thread-continuity-14s.mp4`、`sound.wav`、420 帧对象状态表 `frame-state.json`、代表 PNG 与编码日志。

## 诚实边界
这是为新 Skill 的连续对象/统一时序设计做的**独立 Python 概念片**。没有调用 Remotion 组件、没有真实软件操作，不是 Skill 全链路或客户验收。不能把片子已经编码或静态审帧写成真人全片播放验收。画面含淡入的内部标签，但主表面从头到尾同一对象，非整页切换。

渲染实现帧确定性：状态只由 `frame / FPS` 求值；无网络、墙钟、随机或逐帧累积状态。音频为程序振荡器合成的稀疏提示音，非音乐库曲目。无运动模糊。设计/实现为本任务独立创作，未复制 Lieflat 代码、文案或资产。
